# Handbook Feedback

> 本目录用于记录学习中发现的 Handbook 问题：错别字、概念不清、资料过期、结构建议等。
>
> 每条 feedback 尽量包含：
> - 📎 Handbook 页面链接
> - ❓ 问题描述
> - 💡 建议改法
> - 📝 来源（你发现时的上下文）

## 提交方式

1. 在本目录下创建 `YYYY-MM-DD-topic.md` 文件
2. 保存并与 daily note 关联
3. 定期批量提交到 [GitHub 官方仓库](https://github.com/lxdao-official/aiweb3school)
