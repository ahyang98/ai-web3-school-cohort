# AI × Web3 School — Learning Journal

> Personal learning journal and proof-of-work for [AI × Web3 School](https://aiweb3.school/).

## 📚 简介

AI × Web3 School 是一个面向 builders 的开源学习计划，由 LXDAO 与 ETHPanda 共同发起。  
这门课程系统学习 AI（LLM、Prompt、Agent、RAG、MCP…）、Web3（智能合约、钱包、Account Abstraction…）以及两者的真正交叉点（Chain-aware Context、Agent Wallet、Verifiable AI…）。
